# Tetherbore (working title)

A mobile web mining game that shows off [Pixelbolt](https://github.com/skulitom/Pixelbolt) art and stands as a fun game by itself.

## Goal

Tetherbore is done when a stranger can open one GitHub Pages link on a phone, understand the game in under a minute with no tutorial text, and want to keep playing for twenty. A fixed core sits at the centre of the world; the player's drill hangs from it on a string and, with a swipe, snaps to the next occupied cell in that direction, the string pulling taut behind it. Cutting a chunk of ground completely free, with an open path back to the core, reels the whole chunk in at once, and that haul is the moment the game is built around: it has to look, sound and pay out well enough that players plan bigger and bigger cuts. Each direction from the core (up, down, left, right, and later the sectors between them) is its own biome with its own materials, hazards and transitions, so choosing where to dig is a real decision. Upgrades, with string length first among them, keep opening ground that was out of reach. Every sprite, tile set and effect is made with Pixelbolt, and the game plays at a steady 60 fps on a mid-range phone, in portrait, with one thumb, as a static site with no server and progress saved on the device.

## Pillars

1. **The haul is the reward.** Separate a section, clear its path, watch it fly home.
2. **Snap movement, taut string.** One swipe is one decisive move; the string is always visible and always under tension.
3. **Every direction is a different place.** Biomes differ in material, look and how they give way to the next.
4. **Upgrades change how you dig**, not just numbers: string length, cut speed, haul size, and stranger ones.
5. **Made with Pixelbolt.** The game is the demo.

## Constraints

- Static files only, served from GitHub Pages.
- Touch first, portrait first; desktop works with keys or mouse.
- An original game: its own name, art, materials and levels.
